# Jyoti Swarup Parhi — Developer Portfolio

A futuristic, asymmetrical, cyber-neural developer portfolio for **Jyoti Swarup Parhi**, showcasing full-stack systems engineering, distributed microservices, Generative AI / RAG pipelines, and cloud technologies.

---

## ⚡ Highlights & Features

- **Cyber-Neural Operating System Theme**: Void obsidian backdrop with high-voltage neon cyan (`#00f0ff`), electric sky, matrix emerald, and tactical HUD telemetry.
- **Tech Stack Logos Above Names**: Official vector logos prominently displayed directly above every language and tool across the skills matrix and hero section.
- **Interactive Neural Constellation Canvas**: Background particle field with elastic proximity lines, cursor gravity repulsion, and click shockwave ripples.
- **Cyber Text Scramble / Decoder Engine**: Cryptographic character decoding on titles, buttons, and navigation links.
- **Interactive Live CLI Terminal**: Functional in-browser terminal with executable commands (`help`, `skills`, `projects`, `about`, `contact`, `clear`, `matrix`, `whoami`).
- **Native Web Audio SFX Synthesizer**: Subtle tactile frequency clicks on interactions with an accessible `[AUDIO: OFF / ON]` toggle.
- **3D Card Perspective Tilt**: Physics-driven perspective card rotation tracking mouse coordinates.
- **Distributed Architecture Explorer**: Interactive microservices telemetry map with animated traveling data packets.
- **DSA Code Studio**: Interactive tabbed code engine demonstrating optimal algorithmic implementations (LRU Cache in $O(1)$, Rotated Binary Search in $O(\log N)$, Container With Most Water in $O(N)$).
